## P17 规格断言的用户行为

`e2e/p17-workbench.e2e.js`：

1. 打开已有小说 + 章节（真实 IPC 建立）；
2. 左侧出现章节导航（`chapter-navigator`），列出 ≥2 章，且**恰好一章**处于当前态；
3. 右侧四个页签存在，默认停在「AI 修改」；
4. 切到「人物与世界观」→ 只读面板出现；
5. 切到「运行与恢复」→ 要么出现真实运行状态面板，要么出现「这本书还没有运行记录」的明确空态（不伪造进度）；
6. 点「下一章」→ 路由切到另一章，当前态仍恰好一个。
