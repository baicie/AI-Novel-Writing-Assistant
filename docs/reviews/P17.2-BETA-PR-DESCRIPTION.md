# P17.2：桌面创作可靠性收口（选区改写 / 长文本对比 / 计费边界 / 位置恢复）

## 变更范围

`feature/p17-2-authoring-reliability` → `beta`，70 个文件，+4802 / -106。

## 用户可见结果

### 新增

- 桌面版重新打开后回到上次写作的章节；同一章内的光标与滚动位置也会恢复，
  首页给出「继续上次写作」入口。

### 优化

- 使用本机 Ollama 写作时，没填 API Key 也能用「AI 优化这段」；远程地址仍然要求密钥。
- 长章节的改写对比改为有界实现，五万字章节也能快速给出可逐项挑选的改动；
  改动范围过大时明确提示「只能整段确认」。
- 选区改写的计费状态可见：结果未知时会说明「可能已经发送、结果无法确认」。

### 修复

- 桌面版选中正文后点「AI 优化这段」不再被桌面权限拦截。
- 桌面版采纳改写候选能正常写回正文，并保留修改前的章节历史。
- 桌面版「创建快照」在能力接入前明确提示暂不可用，不再看起来成功却没有保护；
  采纳候选前的保护由章节历史承担。
