## PR 描述草稿

> **摘要**：把模型来源从「单一默认配置」升级为可版本化的 Provider/Model/Binding 注册表，并围绕它补齐可靠性：生成地址规范化、凭据版本化与 CAS、冻结路由、候选稿确认的幂等与 CAS、Worker 租约围栏、计费未知时不自动重发、旧数据兼容。
>
> **迁移**：新增 `0022_provider_registry` / `0023_provider_revision` / `0024_credential_intent`；旧库就地升级，历史 Run 的旧合同可解析并停在安全点，不发起计费请求。
>
> **验收**：A–J 十项旅程全部 PASS，证据见 `docs/reviews/P16.6-R8-*.md`。
>
> **回退**：迁移是纯增量的（新表/新列），旧版本二进制可以直接打开升级后的数据库、不会删除任何数据、也不会删除已写入的密钥槽。**但回退不是「无行为差异」**：旧版本不认识 Provider Registry，会退回使用旧的 `default` 配置；新版本发起的、带 `step_routes` 的 Run 在旧版本里只会按合同里的 `provider`/`endpoint` 走单一路由（冻结路由不再生效）。因此回退只承诺「不丢数据、可启动」，不承诺「进行中的多 Provider Run 行为一致」。
