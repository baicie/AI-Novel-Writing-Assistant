## 四、真实 HTTP 覆盖

`crates/novel-llm/tests/generation_url_http.rs`（axum 本地服务器，严格断言）：

- 内置 `/v1` baseURL → `POST /v1/chat/completions` + `Authorization: Bearer sk-secret` + body 含 model/stream/prompt
- 网关前缀 `/proxy/v1` → `/proxy/v1/chat/completions`
- 历史完整路径 `/v1/chat/completions` → 原样，不重复追加
- 尾部斜杠 baseURL → 正常归一
- Ollama 原生 baseURL → `/api/chat`；Ollama `/v1` → `/v1/chat/completions`
- 未知协议 → 报错且 mock 服务器**零请求**

纯函数层另有 9 条 URL 用例（IPv4/IPv6/无路径/查询参数拒绝/空值拒绝等）。
