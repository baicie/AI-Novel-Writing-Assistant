# P17.3 Native E2E 验收

## 环境与隔离

- 产物：`target/aarch64-apple-darwin/release/bundle/macos/Biz Novel Studio E2E.app`
- 每个 spec 使用独立 `mktemp` 数据目录与独立应用进程（`scripts/run-p172-e2e-isolated.sh`）
- 模型请求全部打到本机 Mock HTTP 服务，不调用付费模型
- 保留 P17.2 的 11 个 spec 与双进程重启验证

## 规格与覆盖

| Spec | 用例数 | 覆盖 |
| --- | --- | --- |
| `p17-3-continuity.e2e.js` | 6 | 人物事实与证据跳转、As-Of、候选确认、冲突裁决、版本失效与重新确认、上下文阻断 |
| `p17-3-context.e2e.js` | 4 | Director 上下文来源追踪、冻结上下文、预览读取当前事实、Context Trace UI |
| P17.2 原有 11 个 spec | — | 保持原有作者旅程、选区改写、编辑位置、Provider 流程等 |

### 连续性 spec

1. 第 3 章只显示此前有效事实，来源链接可跳到第 2 章；
2. 第 4 章仍是「存活」，第 5 章才出现「死亡」；
3. 记忆候选确认前只在候选区，确认后人物状态变为「状态：受伤」；
4. 冲突展示「山门 / 别处」双方与来源，裁决「保留原事实」后只保留原事实；
5. 章节重存后旧事实进入「需要重新确认」，重新确认后过期提示消失；
6. 无书籍产物时，上下文预览显示「本次生成被阻断」并列出 `story_macro` 等缺失来源。

### 上下文 spec

1. 运行时 trace 包含 `structured_story_facts`，冻结的 context artifact 含已确认的
   `life_state=alive` 与人物名；
2. 运行结束后新增 `location=北境哨塔`，历史 Run 的 trace 与 artifact payload 不变；
3. 预览读当前事实（contentHash 改变）；抽取未确认候选后预览 contentHash 不变；
4. 章节工作台「上下文」页签展示版本、预算、来源列表与可生成状态。

## 结果

在最终本地 HEAD 上重新执行：

```
pnpm build:tauri:e2e
bash scripts/run-p172-e2e-isolated.sh
bash scripts/run-tauri-p172-rewrite-restart-e2e.sh
```

| 执行 | 结果 |
| --- | --- |
| `pnpm build:tauri:e2e` | 退出码 0 |
| 13 个隔离 spec（原有 11 + 新增 2） | 13 PASS / 0 FAIL |
| `p17-3-continuity.e2e.js` | 6 passing |
| `p17-3-context.e2e.js` | 4 passing |
| 双进程重启验证 | 6 passing + 1 passing，通过 |

## 说明

- Mock LLM 的 `character_cast` 必须满足至少 3 人，否则运行会按数据完整性安全暂停；
  该暂停是真实业务保护，不是测试环境绕过。
- 上下文预览与运行 trace 的断言都基于真实 IPC、SQLite 与 UI；没有用页面截图代替业务结果。
