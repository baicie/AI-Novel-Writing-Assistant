## 2. 重点复核结论

- **CAS 成功但密钥未落库**：补偿回滚把数据库写回 previous profile（CAS 带本次 revision）；`vault_write_failure_keeps_old_credential_readable` 确认 `secret_ref` 回到 `gw#1`、地址回旧、旧密钥可读、失败者不留密钥。
- **回滚是否会覆盖其他进程的新 revision**：补偿写用 `upsert_provider(previous, Some(revision), ...)`，CAS 不匹配即失败，不会强写；H 用例验证两进程竞争只有一个赢家。
- **不同 command_id 并发确认**：本轮新增 G5.3 —— 两命令并发、内容不同，断言 `ok_count == 1`、正式正文等于赢家内容、`official_version == 1`、无新模型请求。
- **旧 Worker 过期结果被 Fencing 拒绝**：`verify_lease_fence` 在 `start_attempt_fenced`/`mark_remote_started_fenced` 处校验；I2 用例观测到租约有效期内 B 无法接管且请求数不增。
- **日志/错误中的敏感信息**：`rg` 检索 `tracing::*` 与 provider 错误构造，未见密钥输出；合同 JSON 与事件均不含明文（C/D/G5 用例断言）。
