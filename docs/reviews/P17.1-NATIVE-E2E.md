## 新增规格的实际断言链

1. 建两章 + 一个必然失败的 provider（`127.0.0.1:9`），通过真实 IPC 打开 Run，等 worker 跑到需要人处理的状态；
2. 进入第二章，用 `document.execCommand("insertText")` 制造真实未保存状态（`data-local-draft-dirty="true"`）；
3. `window.confirm = () => false` → 点第一章「待处理」→ hash 不变、运行页签未激活、仍为 dirty；
4. `window.confirm = () => true` → 再点 → 跳到第一章、运行页签激活、显示该章自己的 Run 状态。
