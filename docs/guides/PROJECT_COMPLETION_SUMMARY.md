## 📌 **关键设计决策**

### **1. 为什么是 3 层架构？**
```
Component Layer (ChapterEditorShell)
        ↓
API Routing Layer (previewChapterXxxWithRouting)
        ↓
Implementation Layer (handleLocalXxx)
```
- 关注点分离清晰
- 易于扩展和维护
- Component 无需了解路由细节

### **2. 为什么用事件处理？**
- Tauri 本身支持事件流
- 实时反馈用户进度
- 便于中止和恢复

### **3. 为什么保持云模式兼容？**
- 降低风险
- 保留后备方案
- 用户可自由选择
