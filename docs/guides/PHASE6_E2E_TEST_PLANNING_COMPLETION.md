## 🔍 **测试重点**

### **最关键的集成点**

```
1️⃣ UI → API 路由器（模式切换）
2️⃣ API 路由器 → Rust 内核（生成请求）
3️⃣ Rust 内核 → 本地 LLM（生成执行）
4️⃣ 本地 LLM → 流式返回（实时响应）
5️⃣ 流式返回 → UI 显示（渲染更新）

所有 5 个点都在测试覆盖中
```

### **最重要的测试场景**

排序依重要性：

1. **最高**：本地 AI 修正生成（场景 3.3）
   - 包含从 UI 到 Rust 内核的完整流程
   - 验证流式输出
   - 性能基准

2. **高**：生成完成后的候选展示（场景 3.5）
   - 验证 JSON 解析
   - 验证渲染

3. **高**：长时间运行稳定性（场景 6.1）
   - 验证没有内存泄漏
   - 验证连续操作稳定

4. **中**：错误处理（场景 5）
   - 验证应用稳定性
   - 验证用户指导
