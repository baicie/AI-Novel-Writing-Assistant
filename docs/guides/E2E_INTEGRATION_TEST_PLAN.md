# E2E 集成测试验证计划

## 🎯 **测试目标**

完整验证本地创作功能的端到端集成，确保所有 5 个集成点正常工作。

### **验证范围**

```
前端 UI 层
    ↓
API 路由层
    ↓
本地创作适配层
    ↓
Rust 内核层
    ↓
API 响应返回
    ↓
前端显示
```

### **关键测试场景**

1. ✅ **本地创作模式选择** - UI → Router
2. ✅ **密钥配置和保存** - UI → Storage
3. ✅ **本地生成流程** - Router → Rust → Return
4. ✅ **候选方案展示** - Return → UI Display
5. ✅ **云模式兼容性** - Switch to Cloud → Verify
