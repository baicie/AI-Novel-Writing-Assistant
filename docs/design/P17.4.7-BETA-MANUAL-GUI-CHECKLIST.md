# P17.4.7 Beta 人工 GUI 验收清单

> 状态：`MANUAL_GUI_NOT_RUN`。本清单供产品验收人员逐项执行；执行前不要用 Native E2E
> 结果替代人工判断。自动化验收结果见 `docs/design/P17.4.7-BETA-UX-CLOSURE.md`。

## 0. 准备

- 使用 **独立验收数据目录**，不要接触正式作品：
  - 从命令行启动时设置 `BIZ_NOVEL_DATA_DIR=$(mktemp -d /tmp/p1747-manual.XXXXXX)`；
  - 或使用一台专门的验收机 / 独立系统账户。
- 执行备份恢复场景前，先按应用内备份流程完成一次备份，并记录备份路径。
- 涉及模型生成的场景，只有在已明确授权模型、预算与配置时才执行；未授权时把该场景
  标记为 `NOT_RUN`，不要用 Mock 或推测结果代替。
- 截图统一放在 `docs/reviews/assets/p17-4-7/manual/`，命名
  `<场景>-<步骤>-<结果>.png`，例如 `A1-create-professional.png`。
- 每个问题按下文模板记录，并在清单结果列填写 `PASS` / `FAIL` / `NOT_RUN` 与问题编号。

## 1. 场景与判据

### A. 小说创建与恢复

| 项 | 内容 |
| --- | --- |
| 前置条件 | 应用已启动；验收数据目录为空或只有验收作品 |
| 步骤 | 1. 从首页点击「手动创建小说」。2. 填写书名与预计章节数。3. 点击「创建并进入项目」。4. 等待应用自行跳转，不要手动改地址。5. 在工作台点击「章节执行」，创建 1 个章节。6. 完全退出应用并重新打开。7. 从首页点击该作品的「编辑小说」入口。 |
| 预期结果 | 创建后进入专业创作工作台（项目设定步骤），不是简易书架；章节执行可用；重启后仍进入专业工作台；不会出现「暂未接入桌面本地内核」。 |
| 验收判据 | 创建后地址包含 `/edit` 且不包含 `/simple`；「新建章节」可用；重启后同样成立。 |

## 2. 问题记录模板

```text
- 编号：P17.4.7-MANUAL-<序号>
- 场景/步骤：
- 实际结果：
- 期望结果：
- 严重度：P0 / P1 / P2 / P3
- 可复现性：必现 / 偶现（次数）/ 无法复现
- 数据条件：书名、章节、伏笔/事实编号
- 截图或日志路径：
- 备注：
```

严重度约定：

- `P0`：数据丢失、无法创建或打开作品、恢复流程破坏数据。
- `P1`：核心创作链路无法继续，且没有可用的绕行方式。
- `P2`：有绕行方式，但明显影响效率或理解。
- `P3`：视觉、文案、间距等打磨项。
