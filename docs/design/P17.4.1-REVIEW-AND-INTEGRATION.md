## 4. 伏笔状态机与旧写路径兼容矩阵

### 状态语义

| 状态 | 来源 | 可执行动作 | 展示 |
| --- | --- | --- | --- |
| `open` | setup / recover 前 | develop / payoff / defer / abandon | 埋设 |
| `developing` | develop / recover | develop / payoff / defer / abandon | 推进中 |
| `resolved` | payoff | 来源有效时不可再动作 | 已回收 |
| `deferred` | defer | develop / payoff / abandon | 已暂停 |
| `abandoned` | abandon | 终态 | 已废弃 |
| `stale` | 来源失效 / 手工恢复前 | recover / payoff / abandon | 来源失效 |
| `superseded` | 旧记忆冲突 | 只读 | 已失效 |
| `disputed` | 旧记忆候选 | 只读；通过记忆冲突入口裁决 | 待确认 |

### 旧写路径

| 路径 | 是否产生事件 | CAS | 状态处理 | 结论 |
| --- | --- | --- | --- | --- |
| `create_plot_thread` | 是（setup） | 新行 version=1 | 只写 open | 新权威路径 |
| `transition_plot_thread` | 是 | expectedVersion + rows_affected | 白名单 | 新权威路径 |
| 记忆候选确认 | 否 | 候选 version | 仅 `disputed → open`；保留事件行的状态/来源/埋设章 | 兼容，不再重开 |
| 记忆冲突 `supersede_old_facts` | 否 | 无 | 仅无事件行；version+1 | 不覆盖作者生命周期 |
| `upsert_plot_thread` | 否 | 无 | 仅无事件行可改状态；有事件行只改标题/正文；version+1 | 兼容旧导演页 |
| `invalidate_story_facts` | 否 | version+1 | open/developing/deferred/resolved → stale | 历史事件保留 |
| `list_story_facts` | 只读 | — | 事件 As-Of；旧 resolved 按回收章判断 | Director 上下文 |
| `list_plot_threads/events` | 只读 | — | 事件 As-Of + 来源有效性 | 工作台 |

### 字段区分

- `lifecycleStatus`：截至目标章节的事件折叠结果，保留「来源失效前是已回收/推进中」。
- `storedStatus`：数据库原始状态，失效流程可能已写成 `stale`。
- `sourceValid` / `evidencePresentInCurrent`：来源版本与证据是否仍匹配当前正式正文。
- `status`：作者看到的综合状态；来源失效且生命周期活跃时显示 `stale`。

## 6. 事务、CAS、幂等与因果图结果

- 相同 commandId + 相同请求：幂等返回，不追加事件、不改版本。
- 相同 commandId + 不同请求：`Conflict`，不写入。
- 两个连接同时用同一 `expectedVersion`：只有一个成功；另一个冲突。
- 来源版本不匹配、证据不在正文、跨书章节、推进早于埋设：拒绝，状态/版本/事件不变。
- 事件写入失败（重复事件 ID）：整个事务回滚，状态/版本/事件均回滚。
- 因果图：
  - A→B→C 后 C→A：拒绝。
  - 多类型节点（事件 → 伏笔 → 结构化事实 → 事件）：拒绝。
  - 跨书端点：拒绝。
  - 并发 A→B / B→A：只允许一条落库（连续 8 次运行通过）。
  - 来源失效：边保留，`sourceValid=false`；端点失效：`fromValid/toValid=false`。
  - 历史边不因来源失效或章节删除而删除。
