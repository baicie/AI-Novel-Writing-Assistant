## 3. D 场景失败证据

### D1 本书世界创建不可用（P1）

在专业项目打开 `stage=world`，界面完整显示三种来源：

- 根据本书生成
- 从样本库导入
- 自定义空白手册

选择「自定义空白手册」，填写「世界名称 / 一句话概要」并点击「自定义本书世界」后，
页面出现四条：

```text
这个功能暂未接入桌面本地内核
这个功能还没有接入桌面本地内核，请先从已迁移的书稿入口继续。
```

底层记录：

```text
GET  /novels/{id}/novel-world
POST /novels/{id}/novel-world/manual
```

两条路由都没有桌面适配。界面提供了可点击的入口，但所有世界来源操作都失败。
截图：`docs/reviews/assets/p17-4-7/agent/p1747-d-world.png`。

### D2 手动角色创建不可用（P1）

在 `stage=character`：

- 已通过 IPC 播种的角色能正常显示（`character panel has seeded: true`）；
- 「新增角色」弹窗只有「AI 生成角色卡」与「从基础角色库导入」；
- 没有空白手动创建入口（`dialog has manual blank create: false`）；
- 基础角色库页面请求 `GET /base-characters` 未迁移，页面提示未接入；
- AI 生成需要模型，本轮未授权，未执行。

因此，没有可用基础角色且未配置模型时，桌面端无法新增角色。
截图：`docs/reviews/assets/p17-4-7/agent/p1747-d-character-dialog.png`、
`p1747-d-base-library.png`、`p1747-d-character-panel.png`。

### D3 其他未迁移面板

探测过程中还记录到以下缺失路由：

```text
GET  /novels/{id}/volumes
GET  /novels/{id}/volumes/versions
GET  /novels/{id}/quality-report
GET  /novels/{id}/world-slice
GET  /novels/{id}/character-resources
GET  /novels/{id}/characters/{characterId}/timeline
GET  /novels/{id}/director-version
GET  /novels/director/book-automation/{id}
GET  /novel-workflows/novels/{id}/auto-director
POST /novel-workflows/sync-stage
POST /novel-workflows/bootstrap
GET  /book-analysis
```

这些不是 D 场景的全部阻塞项，但说明桌面端仍有较多设置/导演面板没有接入本地内核。
有些面板会降级为空态，有些会直接提示未接入；需要产品确认公开 Beta 是否接受这些限制。

## 4. 严重度与影响

| 编号 | 问题 | 严重度 | 影响 |
| --- | --- | --- | --- |
| D1 | 本书世界创建全部入口未迁移 | P1 | 新手无法完成世界准备；界面承诺可用但操作失败 |
| D2 | 手动角色创建不可用；基础角色库未迁移 | P1 | 无模型/无基础角色时无法新增人物，角色准备链路中断 |
| D3 | 多个设置/导演面板路由缺失 | P2 | 空态或“未接入”提示，可能阻断项目设定、卷规划、质量报告与导演入口 |
| D4 | UI 仍展示未迁移入口，没有提前禁用或引导 | P2 | 用户点击后才看到错误，认知负担高 |

## 5. 门禁结论

| 门禁 | 状态 |
| --- | --- |
| Engineering Acceptance | PASS |
| Automated Product Acceptance | **FAIL（D 场景）** |
| Manual Product Acceptance | `MANUAL_GUI_NOT_RUN` |
| Model Quality Acceptance | `NOT_RUN` |
| 公开 Beta | **不批准** |

核心写作链路（创建、章节编辑保存、连续创建、伏笔、事实、因果、重启、备份）可用；
但“新手完成一本书”的世界与角色准备在桌面端有 P1 缺口，不能把自动化回归通过当成
产品验收完成。

## 6. 建议处理顺序

1. **确认 D1/D2 是否属于公开 Beta 范围**。若属于，先迁移：
   - `GET /novels/:id/novel-world` 与 `POST /novels/:id/novel-world/manual`；
   - 基础角色库 `GET /base-characters` 与小说角色导入；
   - 或提供一个不依赖模型的空白角色创建入口。
2. 对暂不迁移的入口，改为禁用并给出明确替代路径，不要等用户点击后才报错。
3. 重新执行 D 场景，并补一条真实 UI 的因果边创建用例。
4. 人工 GUI 验收与授权模型评测仍按原清单执行，不能用本次 Agent 验收替代。
5. 在 D 修复前，公开 Beta 保持不批准。
