## 项目背景

### 项目目标

构建一个生产级的 AI 辅助小说写作系统，具备：
- 完整的应用架构
- 高可用的 REST API
- 数据持久化
- 用户认证和授权
- 性能监控和可观测性
- 自动化部署流程

### 技术选择理由

**Rust 语言**
- 内存安全，无运行时垃圾回收
- 性能与 C++ 相当
- 类型系统强大，编译时检查
- 优秀的异步生态

**actix-web 框架**
- Rust 生态中性能最优
- 原生异步支持
- 中间件生态完善
- 社区活跃，文档充分

**SQLx 数据库**
- 编译时 SQL 检查保证安全
- 零开销抽象
- 与异步生态天然配合
- 支持多种数据库
